# AX Study

AI Agent 엔지니어 부트캠프에서 학습한 내용을 기록하는 저장소입니다.

Python 기초부터 AI Agent 개발까지 학습 과정을 단계별로 기록하고,
강의 내용과 실습 결과를 함께 정리하고 있습니다.

---

## 학습 목표

- Python 프로그래밍 기초 익히기
- 문제를 코드로 해결하는 사고방식 기르기
- 코드를 모듈화하고 프로젝트 구조를 이해하기
- SQL, FastAPI, AI·LLM 기술로 학습 범위 확장하기
- 최종적으로 AI Agent 서비스를 직접 설계하고 구현하기

## 현재 학습 포인트

### Chapter 06. 코드 모듈화와 프로젝트 의존성 관리

하나의 파일 안에 모든 코드를 작성하는 단계에서 확장하여,
기능별로 코드를 나누고 필요한 기능을 불러와 재사용하는 구조를 학습하고 있습니다.

- 모듈의 개념과 `.py` 파일 단위의 코드 분리
- `import`를 이용한 다른 모듈의 함수·변수 사용
- 관련 모듈을 디렉터리 구조로 묶는 패키지 개념
- 직접 만든 모듈을 다른 코드에서 불러오는 방식
- 코드 재사용성과 유지보수성을 높이는 모듈화
- 프로젝트 내부 파일과 패키지 구조 이해
- 표준 라이브러리와 외부 패키지의 차이 이해
- `uv`를 활용한 프로젝트 의존성 관리 학습 진행
